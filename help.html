PocketPCB

A small editor for schematics and printed circuit boards: draw the schematic, place the parts on the board, lay the tracks, and make the board at a factory or at home by toner transfer.

Projects

  • A project is a folder with its project, schematic and board files and its own copy of the parts it uses, so it opens the same even when the library changes. Projects live in the PocketPCB-Projects folder beside the program unless you choose another (Settings > Projects folder).
  • File > New project, Open project, Save (Ctrl+S), Save as (Ctrl+Shift+S, into a new empty folder). The Save button stands on red while something is not saved; the bottom left corner of the window also shows it, and a click there saves.
  • The last three versions of each file are kept in the project's backup folder. The project is autosaved every five minutes and offered back when it is opened after a crash. You are asked before unsaved changes are lost.
  • File > Save version asks what changed, saves the project and keeps a copy of it as it is now: a zip in the project's versions folder, numbered, with the day and the revision in its name. View > Versions lists them, the newest first. Restore this version brings the one chosen back as one step (Undo takes it back); first it offers to keep the present project as a version too. Open a copy (or a double click) shows a version in a window of its own, for reading only, with an orange band under the drawing: copy a piece of its schematic there and paste it into the project. What is printed to PDF or exported from it goes into the project's out folder, named with the version, as amp-v3-copper-top.pdf.
  • The Recent projects button on the strip opens the last project with a click (Ctrl+Shift+O, also File > Open last project); its arrow, and File > Recent projects, list the last seven. A project opened while the board is shown opens on its board. Each page opens with the zoom and place it was last looked at.
  • Project properties (a button on the strip, also in the File menu):
    • General: the title block (an empty date shows the day of the last save; Next beside the revision gives the one after it), the designator style (R, D, Q, U or GOST R, VD, VT, DD; a new style renames the parts, numbers kept), which sides of the board have copper (both, top only, bottom only); choosing one side asks before deleting the tracks of the other side and the vias.
    • Net classes: add, rename, change and delete classes (track width, clearance, via), and choose the default class and the class of power nets.
    • Rules: the rule set (Manufacturing or Toner transfer, which fills in its values to change by hand), track widths, clearance, edge clearance, annular ring, vias, wire links, solder mask and drills, and for each check whether DRC calls it an error, a warning or nothing. Lists are lengths in millimetres with slashes between, as 0.3 / 0.5 / 0.8.

The window

  • The menus open from the button at the left of the strip, or with F10. Help > User guide (F1) opens this page, Help > About names the version.
  • The strip of tools, left to right: the menu, Recent projects, Project properties, Save, Print and PDF (of the schematic, or on the board Print board); Undo and Redo; Zoom in, Zoom out, Fit the page, Fit the drawing, Actual size, and a grid button that makes the grid brighter while held; in the middle Lock and the tools of the page shown (the one on stands pressed); on the right the panels: Library, Properties, Nets, ERC, DRC, BOM, Versions (Ver). Each tip names its key.
  • Sheets of the schematic are tabs over the canvas; the board is the last tab.
  • The wheel zooms, the right or middle button held pans. Home fits the page, Shift+Home fits only what is drawn (on the board the parts and copper, those off the board too, without the outline), Ctrl+0 shows the real size (set your screen's size in Settings > Screen size for it to be exact).
  • N / Shift+N change the grid step, shown in the status bar. View > Grid style (lines or dots) and View > Cursor (arrow, small cross, full-window cross) choose how they look.
  • A short right click opens the menu of what is under the mouse. Esc stops what is going on, and pressed again drops the choice.
  • Lock fixes what is chosen so that it cannot be moved, turned or deleted until unlocked; locked things are drawn yellow on the board.
  • Undo and Redo (Ctrl+Z / Ctrl+Shift+Z) go to the sheet of the step and choose what it changed.

Library

  • The Library panel lists the built-in parts, your own and those of the project, grouped by what they are (power symbols first, rare groups last), with a search field and a drawing of the symbol and footprint of the part chosen.
  • Your own parts are JSON files in your library folder (File > Open library folder); File > Open library file (Ctrl+L) shows a symbol or footprint file and redraws it each time the file is saved.
  • File > Update parts from library lists the project's parts that differ from the library and updates those you tick.

Footprint editor

  • The Library editor button on the strip opens the footprint chosen under the library list in a tab of the library editor window; with the Library panel closed it shows the window as it was; an empty one offers New footprint and Open… in its middle. Its arrow starts a new footprint. Each tab has its own strip and its own Undo.
  • Over the tabs: + starts a new footprint, Open… picks one of the library from a list with a search field and a drawing of the one chosen, Copy opens a copy of the one shown, to be saved under a name of its own.
  • Pad (P): each click places a pad on the grid, numbered on, like the last one; the arrow offers the usual sizes. Row of pads sets up one column, two columns numbered across or a DIP numbered around; the row follows the cursor by pad 1 and a click places it.
  • The silkscreen: Line (L) goes from click to click until Esc or a double click, across, up and down or at 45°, at any angle with Shift; Rectangle by two corners, with Shift an oval in them, its short sides round; Circle by its centre and a point on it; Arc by its start, a point in its middle and its end; Polygon by its corners, closed on the first one or by a double click; Text (T) is typed where clicked. A short right click, as Esc, calls off what is being placed or drawn.
  • Choose pads, drawings and the REF and VALUE marks with a click, Ctrl+click or a frame; drag them on the grid, R turns them, Del deletes pads and drawings. A corner of a drawing is dragged on its own. A double click types a pad's number or a text. The panel sets number, shape, sizes, hole, copper side and place of the pads chosen, or line, dashes, diameter, fill and the text of the drawings chosen, for all of them at once; with none chosen, those of the next.
  • Pads nearer each other than the clearance of the open project are framed in red, and the status bar says by how much. With two pads chosen, it tells the copper and the centres between them.
  • Body, under the panel, is the part over the board for its picture in three dimensions: a box, a cylinder standing up or one lying, its size (empty for the drawing of the silkscreen), height, how far above the board and its colour from a table of 128 (the colour under the mouse shows at large beside it); Ready-made fills it for TO-92, TO-220, DIP, a resistor, an electrolytic or an LED. It shows dashed on the drawing, and under the fields the part stands on a piece of board in three dimensions.
  • Measure (M): click, then click again; the distance, across and up and down, stays shown until Esc. A point on a pad is taken at its centre.
  • The origin, the point the part is held by and turns about on the board, is the red orange cross with a ring. Origin here (O) moves it to a click; its arrow puts it in the middle of the part.
  • Save (Ctrl+S) writes it into your library; a built-in footprint saved there is replaced by your copy. A new one is named when first saved. Save as (Ctrl+Shift+S, the arrow of Save) saves a copy under a new name and goes on with it; the one opened stays as it was. Rename… there renames a footprint of your library: the old file goes, and your parts listing it take the new name. Built-in parts cannot follow, so you are asked first when some list it.

Schematic

Sheets

  • "+" after the tabs adds a sheet; a double click on a tab renames it; tabs are dragged to reorder.
  • The menu of a tab (or View > Sheet) adds, renames and deletes a sheet and chooses its paper: A4 or A3, landscape or portrait.
  • View > Sheet background picks a pale colour for the paper; the sheet shows it as you move over the table.

Placing parts

  • Drag a part from the Library panel onto the sheet, or double click it and click on the sheet as many times as you need; Esc or a right click ends. The part is copied into the project and numbered on.
  • R and M turn and mirror the part while it is still being placed.
  • A double click on a part on the sheet shows it in the Library panel.

Choosing and moving

  • A click chooses, Ctrl+click adds or takes away, a frame chooses the parts whose drawing is inside it; Ctrl+A chooses all. A click on one of several chosen keeps it alone.
  • Drag to move along the grid: wires follow, laid round the bodies of parts; Shift while dragging tears them off. R turns, M mirrors, also while dragging; Del deletes.
  • Copy (Ctrl+C), cut (Ctrl+X), paste (Ctrl+V) and duplicate (Ctrl+D): what is pasted follows the cursor until a click, onto any sheet or project, its parts numbered on.
  • Lock (the button, the menu or the Locked field in Properties) fixes parts and power symbols; their texts still move.

Wires

  • W draws a wire click by click; Space turns the corner the other way, / (or .) slants it. A wire ends by itself on a pin or another wire. Junction dots appear by themselves.
  • A click on a wire chooses the segment under it, up to a pin or a joint on it: drag it across or delete it. Taken near its end, a wire drags that end alone. A double click chooses the whole wire, Shift+click every wire joined to it.
  • A junction dot is dragged along its wire, the wires ending there following.
  • The menu of a point where wires cross offers Join wires (puts a dot there); that of a dot offers Separate wires.

Power symbols, labels, no-connect marks

  • Power symbols come from the Power group of the library, or from P and the Power button, which place the last one again; the arrow beside the button chooses another. Symbols with the same net name are one net. A double click edits the net name in place.
  • Labels: L, then a click asks for the text; the next one is offered numbered on (D0, D1 …). Labels with the same text are one net. A label joining nothing is white on red. Its text is dragged away from its point; a double click edits it.
  • No-connect marks: X on a free pin of a part; a mark on no pin is red. Marks go with the pin and are deleted with the part.

Buses

  • B draws a bus like a wire; it is named BUS1, BUS2 … and renamed with a double click (for example D[0..7]).
  • A bus drawn to another branches off it and takes its name. Shift+click chooses a bus with its branches. Add name here in its menu shows the name in one more place.
  • A wire drawn to a bus ends on it at 45°; label the wire to say which line of the bus it is.

Designators, values, properties

  • A click on a designator or a value chooses that text alone; drag it to move it. An empty value shows as a grey VALUE mark (not on parts that need none, such as switches and connectors).
  • A double click on a value edits it in place; the menu of a part does it too.
  • The Properties panel edits the designator, value, footprint, off-board flag, lock, comment and, for resistors, the rated power of the parts chosen, several at once; Properties in the menu of a part opens it with the keyboard in its first field. Esc in a field takes back what was typed.
  • A resistor's power is marked inside its body with GOST designators, after the value with international ones (unless most resistors have it).

Nets

  • Rest the mouse a second on a wire, pin, label or power symbol to light its whole net and see its name.
  • The Nets panel lists every net with its class and pins, with a filter. Choose a net's class there; a chosen row lights its net. A grey name (TempN1 …) may still change; a net gets a lasting name (NN1 …) once given a class or when the board is updated.

ERC

  • The ERC panel checks the schematic after every change while it is open and a sheet is shown (a project just opened waits for a change or Check): empty values, repeated designators, free pins, a designator a wire link on the board has too, misplaced no-connect marks, loose labels and wire ends, wires lying on wires or closing a loop, a two-pin part shorted, a net with two names and so on.
  • While it is open the problems are ringed in red on the sheet; a problem chosen shows its place, and an empty value opens for typing.

BOM

  • The BOM panel lists the parts, alike ones in one row, under group headings. The value and comment are typed in the table; a double click on designators shows those parts. The board's wire links follow under Wire links, a row for each length of wire to cut; an insulated one has some to spare.
  • Its buttons write the list as TXT, CSV or PDF into the project's out folder.

Printing

  • File > Print schematic (Ctrl+P) prints the sheet shown, all sheets or a range, black on white, each fitted to the paper.
  • File > Export schematic to PDF writes the sheet shown or all of them at 1:1 into the out folder.
  • The board prints 1:1 for making it at home: see Printing the board.

Board

From schematic to board

  • Update board from schematic (F8, or its button left of Lock) shows what will change and brings the board in line: new parts are packed to the right of the board, removed ones go with their tracks, values, designators, footprints and nets follow; parts already placed stay where they are. A part given another footprint keeps its tracks on the pads of the same numbers, unless one would cross another net.
  • Parts marked off-board in Properties (jacks, switches on the panel) do not come to the board.
  • While two different nets have one name, say a label named like a name in the Nets panel, the board is not updated: rename the label or the power symbol (ERC shows where).

Seeing the board

  • Top copper is red, bottom copper blue, vias violet, silkscreen white (bottom grey), the outline lilac. A cyan corner marks the origin of the coordinates.
  • Light green lines (the ratsnest) show which pads are still to be joined; a line goes out once tracks join its pads. The nets of the parts chosen are lit brighter.
  • A right click on the empty board, or the View menu, chooses what is shown:
    • Hide silkscreen hides the drawing of the parts and their texts; pads, holes and copper stay, and parts are not chosen then.
    • Hide tracks hides the tracks and vias for a while, to see what is still to be joined; the Track tool shows them again.
    • Bold unrouted draws every connection still to be routed bold, with its ends marked.
    • Unrouted as arcs bends those lines, so that lines from one pad part.
  • The menu of the empty board also has Spread tracks, which moves the pieces of tracks between corners to the middle of the room they run in, and Delete all tracks, vias too, which asks first.
  • The status bar shows how many connections are unrouted, of all of them.

Outline

One button on the strip makes the outline; its arrow chooses what it does, and the button keeps the last choice.

  • Rectangular board asks for the width and the height and makes the board from the origin. Its arrows step a cell of the grid; any size may be typed. It replaces the outline there was.
  • Outline draws a board of any shape: click each corner on any grid point, the sides at any angle; a click on the first corner closes it and the new outline replaces the old one. An outline that crosses itself is refused. Esc drops the corners drawn.
  • Cut-out: drag a rectangle across the edge to take that piece off the board, for a notch or a cut corner. It must reach over the edge and must not cut the board in two; the status bar says why one is refused.
  • While drawing or dragging, the coordinates of the corner stand beside it (View > Coordinates while drawing the board turns them off).
  • In Select the corner or edge under the mouse is lit:
    • drag a corner to move it along the grid;
    • drag an edge to move it, the edges beside it stretching after it (a level edge goes up or down, an upright one sideways);
    • double click a corner, or choose Round board corner in its menu, and type the radius in millimetres (0 makes it sharp again).
  • A double click on an edge chooses the whole outline; drag it to move the board. Ctrl+A chooses the outline with all parts, holes, tracks and vias, to move everything together; hidden silkscreen and tracks show again.
  • Lock (the button or the outline's menu) fixes the outline: it is not dragged, redrawn or cut until unlocked.

Parts

  • Click, Ctrl+click or a frame to choose; drag to move along the grid, pad 1 landing on it; R turns by 90°, also while dragging. Tracks ending on the pads of a part or a hole follow it: their last piece stretches. A track that would cross another net is deleted instead, and its connection shows as unrouted.
  • F (Flip to other side) puts the parts chosen on the other side of the board, mirrored: each about its own axis that keeps its pads where they were, as a resistor's; their silkscreen goes to that side, tracks on pads through the board stay on them, and tracks on pads that went to the other side are deleted.
  • Designators and values are dragged on their own; a chosen text shows a line to its part.
  • The menu of a part: Rotate, Flip to other side, Lock or Unlock, Show or Hide value, Line to part (a bold silkscreen line from the part to its texts), Show on schematic, Delete.
  • Del moves the parts chosen off the board, to the right of it: parts come and go with the schematic. Locked parts stay. Their tracks are deleted: from each pad up to the next pad or fork.

Mounting holes

  • The Hole button places holes, a click each on the grid; its arrow chooses the diameter from the drill set of the project, or another one typed; the last one stays. Esc ends.
  • Holes are chosen, dragged and deleted like parts; a hole deleted takes its tracks with it.
  • The menu of a hole: Lock, diameter, Copper pad (its diameter, 0 for none; it can go without plating, for a board made at home), Plated, Pad side (both, top, bottom), Pad net (puts the pad on a net, joining it to the ratsnest), Delete. Plated gives a 1 mm ring and, taken off, takes it off again; a ring that would come onto another net's copper, by any change or a drag, is refused.
  • A plated hole has a white wall; every hole has a cross in its middle.

Tracks

  • Track (T): click on a pad, a via or a track to start; each click lays a straight piece and one at 45°; a click on copper of the same net ends the track. The pads of the net are lit while you lay it.
  • Space puts the slanted piece first or last; hold Shift for one piece at any angle.
  • V puts a via and goes on on the other side; without a track it switches the side. The side you work on is bright, the other darker. The Layer button does the same, and its arrow chooses the side.
  • The width comes from the class of the net. Esc, a right click or a double click ends the track; Esc again leaves the tool. Ctrl+Z while laying takes back the last click and goes on from the point before. Undoing a via brings back the side it was laid from.
  • A click on a track or via chooses it, Shift+click all the copper joined to it, through pads too, with the unrouted connections of its net bold, a double click the whole track up to a pad or a fork (where three tracks meet or one ends on the middle of another), a frame those inside; Del removes them. The menu of a track sets the width (any, typed under Other…) and the side, and Spread tracks moves the tracks chosen to the middle of their room. Tracks chosen together with parts go along whole when the parts are dragged.
  • Drag a piece of track to move it across itself, the pieces beside it following; taken near a corner, drag the corner (Shift: straight at any angle). A move that would come too near another net is refused.
  • A wire link is a bare wire on the side of the parts between two pads, for a board with copper on one side where a track cannot go. Each is named xx1, xx2… on the silkscreen; drag the name to move it aside. A click on one of its pads chooses it; Del removes it, and Replace with track in its menu lays its connection as a track instead, when there is a way.
  • Rest the mouse on copper for a second to light its whole net and see its name; while tracks are chosen, only the name shows.

Autorouter

  • The Autoroute button lays the tracks of every connection still unrouted; its arrow offers Route all and Route chosen (the nets of the parts and tracks chosen).
  • It lays as few vias as it can, on both sides of a board of two, keeping the clearance of the net classes and of the edge, and keeps tracks away from other nets where there is room. The tracks it laid are then moved to the middle of the room they run in. Tracks laid by hand stay as they are.
  • On a board with copper on one side, where a track cannot go the autorouter lays a wire link, level or upright, 5.08 to 30.48 mm long; it is dearer than any way round, so there are as few as can be, and it goes under a part only when a short way round does not avoid it. Where that cannot go either, it lays an insulated one, drawn dashed, any way and up to 150 mm long.
  • When a connection finds no way, the autorouter takes up tracks it laid itself that are in the way and lays them again. A track it laid counts as laid by hand once you drag it or change its width or side.
  • Esc or Stop in its box stops it, keeping what is laid. The whole run is one step of Ctrl+Z; at the end a box shows the connections there were, those routed and unrouted, the vias, the wire links and the time.

DRC

  • The DRC panel (its button on the strip, or View) checks the board after every change, while it is open and the board is shown (a project just opened waits for a change or Check), against the project's rules: shorts, clearances between copper of different nets and to holes, copper near the board edge, narrow annular rings and tracks, drills not in the set, parts off the board and unrouted connections. Errors come first, then warnings.
  • While it is open the problems are ringed on the board, red for errors and orange for warnings; a problem chosen shows its place with what it is about chosen. Check checks again and shows the board.
  • The pads of one part are not checked against each other.

Printing the board

  • File > Print board (Ctrl+P while the board is shown, or Print and PDF on the strip) prints a layer 1:1 for toner transfer or photoresist: the copper of a side, or its silkscreen. A picture beside the choices shows one copy as it will be printed.
  • Mirrored is on for the top and off for the bottom at first. Negative for photoresist prints the copper white on black. Centre holes leave a small hole in each pad, 0.5 mm at first, for the drill; a hole without a pad gets a circle at its edge and a cross over its middle.
  • Registration marks are crosses outside the board, to put the prints of the two sides over each other. Several copies fill the page and go on to the next.
  • Print asks the printer; Export board to PDF writes the layer into the out folder. Each page has a 100 mm ruler: measure it to check that the printer keeps the scale. Under it, for the copper, the drill table says how many holes of each diameter there are.
  • The layer is printed solid black, in grayscale. In the printer's own settings turn toner saving off and the density up, for the darkest print.

Files for a factory

  • File > Export Gerber and drill files writes the files a factory makes the board from into the out/gerber folder: copper, solder mask, silkscreen and outline in Gerber, the holes in Excellon, plated and not plated apart.
  • The same files go into one zip archive in out, named with the project, its revision (from Project properties) and the day as 20261125: upload it to the factory's site. A box says when it is written.
  • First the revision is asked, the current one filled in. A new revision is written into the project, so the title block shows it too. The project is saved, and kept as a version when it changed since the last one, so you always know what went to the factory.
  • When the files are written, Start revision B in the box moves the project on to the next revision (A to B, 3 to 4) for the changes that follow.
  • With the Toner transfer rules each hole is drilled with the nearest drill of the set not smaller than it. The board needs an outline.

Settings

  • Language: the interface language, or the system's; taken at the next start.
  • Screen size: the diagonal of your screen, or a line measured with a ruler, so that Actual size is exact.
  • Wire routing: Around obstacles (wires that follow a moved part take the cheapest way round) or Simple.
  • Projects folder: where new projects go and opening starts.
  • Keep a history of steps: writes the last 25 steps of a saved project into the history folder beside it, to show what went wrong when reporting a fault.
